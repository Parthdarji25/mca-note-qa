Create a fine-grained token

  1. Open GitHub → Settings → Developer settings → Fine-grained tokens and choose Generate new token.
  2. Under Repository access, pick Only select repositories and choose this repository only.
  3. Under Repository permissions, set Contents to Read and write.
  4. Set an expiry date (30 to 90 days is a good choice).
  5. Generate the token, copy it, and paste it here.

Never share the token, post it in an issue, or commit it to the repository. If it leaks, delete it in GitHub settings straight away.
