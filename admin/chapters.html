File naming

  • Path: qa/sem-N/subject/chNN-title.md (or .html)
  • Lowercase, words joined with single hyphens.
  • Chapter number is two digits: ch01 to ch14.
  • & becomes and; other symbols become -.
  • One file per chapter, either .md or .html, never both.
  • The path is generated for you; you never type it.
