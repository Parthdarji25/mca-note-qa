File naming

  • Path: qa/sem-N/subject/questions.md (or .html)
  • Lowercase, words joined with single hyphens.
  • One file per subject, either .md or .html, never both.
  • Images: images/name.png in the subject folder.
  • The path is generated for you; you never type it.
